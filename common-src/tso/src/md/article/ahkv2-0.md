### ・ スクリプトの書き方


メモ帳などのエディターで`新規作成`からファイルを作ってください

::: note
ファイルの拡張子は`.ahk`です
:::
::: note warn
ファイルのエンコードは必ず`UTF-8 with BOM`にしてください。
UTF-8のままだと表示がバグります
:::

例えば、`Enter` キーを押した際に、**メッセージボックスから Hello World** と
表示されるようなプログラムは以下の通りです
<br>

``` AutoHotkeyv2:helloworld.ahk
; v2を使うよ～というおまじない
#Requires AutoHotkey v2

; 再度同じファイルが実行されたら、前の実行を停止してから実行を開始しますよ～というおまじない
#SingleInstance Force

; Enterキーが押されたら
Enter::
{
    ; あらかじめAutoHotkey側で用意されているMsgBox関数の第一引数にメッセージを入れる
    
    MsgBox("Hello World")
    
    ; v1からの伝統で書いているが、書かなくても良い
    return
}

; このスクリプトの実行を終了する
ExitApp()
```
::: note
コメントアウトをするときは
・一行の場合は、セミコロン`; `
・複数行の場合は`/*  */`
で囲む
:::

### Q: まさか、、、A~Z全てのキーを割り当てたいときにもこれを書かなければならないのか・・・？


### A: ご安心ください。んなこたぁありまへん。

全てのキーを割り当てたいとかいうよくわからない使用方法に目覚めた際に、役に立つ**文**が存在します。

それは
#### For 文です
<br>

そうです。
AutoHotkeyはv2に進化して以降、**まるでプログラミング言語のような書き方** になりました。

もちろん、forの他にもif、switch、whileだってあります。
配列、オブジェクト、Mapだってあるんです。
気になる方は<a href="https://ahkscript.github.io/ja/docs/v2/">クイックリファレンス</a>をお尋ねください

それでは、A~ZをFor文を使用してホットキーにセットするやり方を紹介します。
（ついでに変数の宣言と代入もやります）


``` AutoHotkeyv2:AtoZ_useFor.ahk
#Requires AutoHotkey v2
#SingleInstance Force

; 一番外側の変数の前には global を書きます。
; 変数への代入は、 = （イコール） ではなく、:= (コロン + イコール) です

global atoz_array := ["a", "b", "c", "d", "e", "f", "g", "h", "i", "j", "k", "l", "m", "n", "o", "p", "q", "r", "s", "t", "u", "v", "w", "x", "y", "z"]

void_func() {
    ; キーの入力を強制終了
    return
}

for key in atoz_array {
    ; A~Zのキーを使用不可能に
    Hotkey(key, (*) => void_func())
}

; スクリプト終了用
Enter::
{
    MsgBox("スクリプトを終了します")
    ExitApp()
}
```

::: note warn
上記のスクリプトを実行すると、A~Zのキー入力が全てキャンセルされます
解除したい場合は`Enter`キーを押してください
:::
